# Carolina Luján - Portfolio

Este repositorio contiene mi Currículum Vitae interactivo, desarrollado con Angular y diseñado con una estética gamer (o eso se intentó).

La idea es mostrar no solo mi perfil profesional y mis conocimientos, sino también un poco de quién soy, los proyectos en los que trabajé y mis intereses fuera de la programación.

## ✨ ¿Qué podés encontrar?

- 👩‍💻 **About Me** — Un poco sobre mí, mi recorrido y por qué elegí el mundo de los videojuegos.
- 🛠️ **Skills** — Tecnologías, herramientas y soft skills.
- 🎮 **Proyectos** — Trabajos realizados durante mi formación.
- 🎨 **Ilustraciones** — Algunos de mis primeros trabajos explorando la ilustración digital.
- 📜 **Certificaciones** — Cursos y certificaciones realizados.
- 📬 **Contacto** — Diferentes formas de encontrarme.

## ✨ Tecnologías utilizadas

- Angular
- TypeScript
- HTML
- CSS
- Git / GitHub

## ✨✨ Objetivo

Presentar mi perfil de una manera atractiva, accesible y diferente a un CV tradicional, combinando mi lado técnico con mi lado creativo.
